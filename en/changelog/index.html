Version notes

Development preview. An App Store download is not yet available. Updated September 7, 2026.

0.4 (5) · Test update

Improved the search safe area and saved-route visibility, refined follow controls and final arrival, added the export compliance declaration, and enabled the published support website. This is a test version; the planned public release is 1.0.

0.4 · Preview

Baseline version 0.4 (4). Place suggestions, search results ordered by distance, wider search and map selection. Walking, driving and cycling routes show the complete path with up to seven key points, directions, nearby references and actions on arrival.

Following and sharing

Follow in the foreground, pause, continue, return to the previous stop and confirm arrival manually. Create a route image or open Apple Maps.

About & Help

Offline product information, a usage guide, privacy policy, common questions and version notes. Check location permission, open system settings and prepare feedback email. The displayed version comes from the installed app.

Still to be tested

Landmark reliability across cities, cycling coverage, real-world route use, and VoiceOver and larger text on devices still need testing. There is no rerouting, background navigation, lock-screen guidance, account or cloud sync.
