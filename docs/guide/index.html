第一次用拐弯

出发前花一点时间看整条路，到了关键位置再确认下一步。

1. 找到你要去的地方

允许 App 在使用期间获取位置，输入目的地并核对名称、地址和距离。结果不合适时，补充城区或道路名称、扩大范围，或使用地图选点。地图选点用于选择目的地，当前生成真实路线仍需要当前位置。

2. 选择出行方式，生成草图

可以选择步行、驾车或骑行。App 会按距离推荐方式，你也可以主动切换。等待搜索或路线生成时可以取消；改变搜索词后，旧请求的结果不会覆盖新搜索。

3. 先看完整路线，再看节点

地图保留完整路线线条，只突出少量关键节点。轻点地图节点或路线索引，查看节点名称、估算距离、抵达方式以及到达后的动作。地标缺失时，节点可能使用道路或路口名称。

4. 在前台跟随

跟随时仍能看到整张路线。需要停下时可暂停，也能继续或退回上一节点。进入最后一段不代表已经到达；抵达目的地后，请手动确认完成。

5. 分享图片或查看完整导航

“分享图”会生成包含地图、路线、目的地与节点说明的静态图片，通过系统分享面板保存或发送。图片不是实时位置链接，发出后不会随你的移动更新。

需要详细导航时，选择“在 Apple 地图中查看”。拐弯会传递起点、终点和出行方式；Apple 地图可能根据当前条件生成不同的路线。

当前使用边界

  • 搜索、路线和地图图片生成依赖网络与地图服务，不提供完整离线导航。
  • 没有偏航检测、自动重算、后台持续导航、语音逐转弯或锁屏提示。
  • 骑行路线取决于当地地图服务覆盖，不会把其他方式的路线当作可靠骑行路线。
  • 地标由附近兴趣点生成，尚不能保证在道路正确一侧或实际视野中可见。
  • 距离和时间为估算。道路标志、交通规则与现场状况优先；驾车或骑行时请在安全停下后操作。
