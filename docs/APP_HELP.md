# App 内关于与帮助

## 已接入

首页 Logo 右侧的“关于与帮助”按钮打开独立导航面板；关闭后返回原搜索页。打开时收起键盘并取消仍在等待的搜索或路线请求，避免帮助页遮挡期间发生意外跳转。

- 产品介绍、使用说明、隐私政策、常见问题与版本记录为原生 SwiftUI 文本，不依赖官网和网络。
- 显示当前安装包的版本和构建号，不硬编码界面版本号。
- 定位权限显示当前授权状态；从系统设置回到前台时刷新。打开帮助页本身不会请求定位。
- “打开系统定位设置”使用 iOS 官方 App 设置地址；位置权限的具体选择交给系统。
- 反馈入口打开邮件 App，预填版本号与问题模板；不会自动发送或附加位置。邮件 App 无法打开时给出提示，支持选择或复制邮箱。
- GitHub 和第三方隐私说明明确标记“联网”。官网入口由 `AppInformation.websiteIsPublished` 控制，当前为 `false`，须部署并验证官网后再开启。
- Debug / Release 的定位用途文案均已与搜索、三种出行方式及前台跟随对齐。

## 维护位置

- `TurnCue/App/AppInformation.swift`：邮箱、外部网址、官网发布开关与动态版本号。
- `TurnCue/Features/About/HelpPage.swift`：离线文案，与 `docs/` 对应页面一起维护。
- `AboutView.swift`：入口目录、权限、联系方式。
- `HelpDetailView.swift`：详情阅读界面。
- `SupportContactView.swift`：邮件准备、失败提示与复制邮箱。

没有新增账号、云同步、后台定位或没有实际作用的配置开关。本轮不调整版本号，不代表发布。

## 人工验收

1. 首页打开“关于与帮助”，逐个阅读五个页面，返回目录并关闭；搜索词和已选目的地仍保留。
2. 搜索等待时打开帮助，确认请求取消且不会跳转到路线页；关闭后可重新搜索。
3. 无网络时打开全部帮助内容，确认可阅读；大字体与 VoiceOver 下检查换行、导航标签和阅读顺序。
4. 在系统设置修改定位权限后返回 App，确认显示更新；首次打开帮助不应弹出定位权限请求。
5. 准备反馈邮件，检查版本和模板后取消；没有可用邮件 App 时确认错误提示与复制邮箱退路。
6. 深色系统外观检查纸色背景上的文本和导航栏对比度；确认官网入口当前隐藏。

自动编译与模型检查不能替代上述真机或视觉验收。此轮未操作模拟器、设备或邮件界面。
