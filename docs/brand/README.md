# 拐弯视觉资产

首发视觉基于“城市旧图册”：暖纸色、近黑墨色、朱红路线，以及表示会合点的套印圆环。

## 资产

- `turncue-app-icon-master.png`：1024 × 1024 App Icon 母版。图标不含文字、不绘制圆角。
- `BrandMark.imageset/brand-mark.svg`：透明背景矢量徽记，供应用界面和导出图片使用。
- `turncue-logo-lockup.svg`：适合文档、项目页和宣传图的横向 Logo 组合。
- `BrandLogoView.swift`：由矢量徽记、中文名和小型英文标注组成的运行时 Logo。

## 已选方向

首发采用 **A / 城市旧图册**。正式 App Icon、矢量徽记、应用内 Logo 和路线图导出均以此为准。

`concepts/` 继续保存三套探索记录：

- `A-atlas-print.png`：城市旧图册。当前正式方向，保留道路网、纸张和套色印刷感。
- `B-transit-seal.png`：交通印记。去掉地图细节，只保留路线与会合点。
- `C-field-explorer.png`：野外手记。使用手工油墨、等高线和更强的探索氛围。

B/C 不进入首发应用，可作为未来主题研究的起点。

## 不变量

- 品牌徽记始终表达“一条粗略路线 + 一个当前会合点”。
- 主题可以改变纸张、地貌和节点装饰，但不改变徽记的基本几何关系。
- 不使用定位针、折叠地图、指南针或导航箭头作为主标识。

- 墨色：`#121A1A`

- 路线描边：`#F8EFCF`
