隐私政策

更新日期：2026 年 9 月 7 日 · 适用于当前 0.4 原型

拐弯（TurnCue）提供路线草图。当前版本无需账号，没有开发者自建的数据接收服务，不集成广告或第三方分析 SDK，也不进行跨 App 跟踪。

位置权限

在你允许后，App 使用当前位置查找附近目的地、计算起点和在前台跟随路线。当前仅请求“使用 App 期间”的定位权限，不提供后台持续导航。你可在 iOS“设置 → 隐私与安全性 → 定位服务 → 拐弯”中调整或关闭权限；关闭后，依赖当前位置的搜索和路线生成功能将不可用。

搜索、地图与路线请求

地点补全、地点搜索、路线计算、附近地标和地图快照使用 Apple MapKit 服务。搜索词、搜索区域、起终点坐标及出行方式会按请求需要交给地图服务处理。这些功能需要联网，并非所有处理都只在本机完成。

Apple 及当地地图服务提供方的数据处理遵循其政策，详见 Apple 地图与隐私。开发者不会通过自建服务器接收这些地图请求。

路线状态与保留

当前代码没有实现账号、云同步或路线历史数据库。搜索结果、路线和跟随状态供当前运行使用，不提供长期路线历史查询。操作系统与地图服务可能管理自己的缓存，其处理不等同于开发者保存路线历史。

主动分享与跳转

只有当你主动使用系统分享面板时，路线图片才会交给你选择的 App、服务或保存位置。图片可能包含起点、目的地、沿途地标和路线，分享前请检查是否暴露住址或其他私人地点。已保存到相册、文件或发给他人的副本，需要到对应位置单独管理；结束路线或卸载拐弯不会撤回它们。

选择“在 Apple 地图中查看”时，App 会把起点、终点和出行方式交给 Apple 地图。后续处理遵循 Apple 地图的设置与隐私政策。

支持邮件与网站

如果你主动联系开发者，邮件服务会传输你的邮件地址、正文和附件，开发者会用这些信息回复和排查问题。请勿发送精确住址、完整出行轨迹或其他敏感信息。需要处理已发送的信息时，可通过下方邮箱联系。

本网站不嵌入统计脚本、广告、外部字体或跟踪 Cookie。网站计划由 GitHub Pages 托管；访问时托管方可能处理 IP 地址等访问日志，详见 GitHub 隐私声明。

政策更新与联系

后续如增加账号、持久化存储、云服务或分析功能，会在相关版本发布前更新说明。隐私问题请联系 zhouwei@linux.com，或查看支持页面。
