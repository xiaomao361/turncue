# 交互打磨 · 2026-09-07

保留纸质地图风格和关键节点路线的产品定位。本轮借鉴 Shouxia 的既有经验：主动作说清后果，误操作有退路，异常反馈出现在操作附近。

## 当前交互约定（第二轮）

本节为当前实现；下方第一轮记录保留作改动背景。

| 页面或状态 | 主动作 | 辅助操作 |
| --- | --- | --- |
| 搜索 | 查找目的地 | 地图选点 |
| 搜索结果 | 先选地点，再在底部查看路线 | 重新搜索、其他地点、没找到菜单 |
| 地图选点 | 底部确认目的地，返回后选择出行方式并查看路线 | 顶部取消 |
| 路线预览 | 开始跟随 | 地图旁显示全程；菜单分享和 Apple 地图 |
| 当前节点 | 我已到达这个节点；最后一段为确认到达目的地 | 菜单暂停、退回 |
| 查看其他节点 | 返回当前节点，不推进进度 | 展开全部节点可继续查看 |
| 暂停 | 继续跟随，回到当前目标 | 菜单退回 |
| 完成 | 返回搜索 | 菜单撤销到达、分享 |

- 搜索结果卡片用选中标记表达选择，不再点击即生成路线；没有默认替用户选中最近地点。
- 出行方式在选地点后出现；确认区同时显示目的地名称，避免操作对象不明。
- 路线底部采用浅色状态说明加一个深色主按钮。分享、Apple 地图、暂停和退回只在菜单保留一个入口。
- 全部节点默认折叠，展开后用紧凑列表；详细指引只显示所选节点的一份。详情明确区分预览、当前目标、已暂停和查看其他节点。
- 手动确认必须匹配当前节点 ID；浏览其他节点、空选择和已推进节点的迟到确认都不能推进路线。
- 定位推进时，只在正在查看原当前节点的情况下同步选择；保留用户正在查看的其他节点。

第二轮检查：通用 iOS Simulator 编译和无界面核心检查通过，新增其他节点误确认、迟到确认、撤回后重新确认和重复到达保护。未操作模拟器或手机 UI，未重新安装设备。

人工重点：点卡片是否能理解为选择；确认区是否清楚；展开其他地点后切换选择；地图选点取消是否保留原选择；查看其他节点后点主按钮只回当前节点；暂停与恢复是否易找；检查窄屏及大字体布局。

## 第一轮已实现

- 搜索：输入时收起介绍文字；清除按钮；空查询不可提交；结果自动滚动到确认区；最近地点不再被文案暗示为最正确的地点，距离标明为直线距离。
- 出行方式：搜索页提供按距离推荐、步行、驾车、骑行；地图选点也使用此选择；路线页显示实际方式。
- 异步操作：搜索、定位选点和路线生成共用一个可取消任务；阻止重复提交；编辑搜索词、离开页面或取消后，旧响应不再更新界面或跳转。取消是协作式的，已发出的 MapKit 请求可能等待系统返回，但结果会丢弃。
- 定位：授权后请求位置最多等待 15 秒；系统权限弹窗等待不计入超时；拒绝后显示设置入口；缓存位置也先检查权限。
- 路线：原生返回导航；目的地和距离从地图遮罩移到标题区；地图从 500 点缩到 320 点；全览按钮恢复整条路线；显示当前位置；减少底部重复占位。
- 节点：列表用原生 Button，选中时显示标记并滚动到详情；定位推进会同步当前节点选择；关键动作有轻量触觉反馈。
- 跟随：明确区分开始、暂停、继续、完成节点、确认到达及返回搜索；进入最终路段不等于已经到达；退回操作会暂停跟随，防止当前位置立即把节点再次推进。
- 分享：生成进度与失败说明靠近底部分享按钮；系统分享面板由用户决定保存或分享；离开路线页后不再展示迟到的导出结果。
- 可访问性：补目的地字段、清除、节点和操作菜单语义；按钮状态与选中标记；减弱动态效果；重点操作至少 44 点。人工辅助功能验收仍待进行。

## 已验证的层次

- Xcode 通用 iOS Simulator 目标编译通过，未启动模拟器或操作设备。
- 无界面核心检查通过：样例路线、压缩算法、终点确认、完成幂等、撤回、重启、定位距离/精度限制、单节点路线。
- 编译有系统工具提示未依赖 AppIntents.framework 而跳过元数据提取；未见编译错误。
- 网络、权限弹窗、地图与分享面板未进行运行时交互验收。

## 人工试用清单

1. 输入地点、点建议、换词、快速连点搜索、取消后重搜：不得出现旧地点或重复跳转。核对键盘出现时输入与建议的位置。
2. 拒绝定位、定位不可用、断网及无结果：能看见解释并恢复；网络恢复后可以重试，不一直处于等待。
3. 核对同名地点和地址；切换出行方式；直接地图选点后生成路线。骑行覆盖取决于 MapKit，需实测。
4. 拖动地图后点全览；分别点地图节点和列表行：选中状态、详情与当前跟随节点能分清。
5. 开始、暂停、继续、推进、退回；到最终路段时仍显示确认到达，完成后能撤回或返回搜索。
6. 生成分享图、取消系统面板、失败后重试、生成时返回上一页；不得出现迟到面板。
7. 小屏、大字体、VoiceOver、减弱动态效果：核对底部控制区、长地点名、地图点选、滚动与按钮焦点。
8. 前后台切换：后台停止位置更新，回前台恢复；实际步行验证节点和地标可靠性。本版本仍不提供后台导航或偏航重算。

## 保留的边界

这是一轮源码与状态流打磨，不能代替地图点选、滚动手感或实地路线验收。MapKit 原始路线压缩及地标推断策略未在本轮重新校准。
